## GET operations and filtering

`inventory` creates fixed, typed resource operations. `requestDescriptor` accepts only frozen operations registered by that inventory, constructs the GET and selector itself, and registers the resulting immutable descriptor. `hostedTransport` rejects unregistered descriptors and any other method, rejects redirects, does not read error bodies, and never discovers ambient credentials. Only the standard masked auth action's access-token output is consumed. No credentials file, fallback identity, ADC discovery or SDK auth command is used.

`schemas` generates server-side `fields` selectors and rejects every unexpected returned field recursively. Stored data is rebuilt through an independent allowlisted `serialize` boundary. There are no environment values, annotations, labels, secret payloads, arbitrary commands, arbitrary API URLs or product/provider requests. Human IAM members and condition expressions exist only in bounded request memory; output contains binding/member counts and runtime/deployer invoker comparisons, never raw members or expressions. The deployer secret configuration is never emitted as an identity, path or error text.
