# 公開費率版本：既有 P5 畫面的功能接線

依據 `platform-p5.jsx` 的 `PA_P5Fare`，以及已定案的 P5-FARE-001／
P5-FARE-PUB-001，沿用原有標題、左側版本表格、右側公開預覽卡片及
「建立版本」「排程生效」控制項。這份文件補足既有操作所需的欄位與狀態，
不新增獨立頁面、對話框、配色或角色權限。

2026-10-10 的使用者費率決定優先於 canvas 的舊示例：目前資料讀取正式
API；示範起始費率使用 85 元／1250 公尺、5 元／200 公尺、5 元／60 秒、
夜間固定 20 元。舊例的 80 秒、百分比夜間加成及示例備查文號不可代表現況。

| 操作           | 既有畫面內的呈現                                       | 成功／失敗行為                                                                            |
| -------------- | ------------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| 列表、預覽     | 左表選版本，右卡顯示實際參數、來源、生效區間、備查資料 | 載入中、空資料、失敗與重試分開；讀取失敗時不以靜態示例取代正式資料                        |
| 建立／編輯草稿 | 右卡改為表單；沿用表單 token，保存或取消後回預覽       | 提供版本 ID、名稱、摘要、來源、計畫時間及全部既有計價參數；保留具名附加費，金額為整數 TWD |
| 記錄備查       | 草稿右卡內輸入實際備查文號與證據識別                   | 只記錄操作者提供的資料，不宣稱已連線或驗證主管機關；無資料時可進示範                      |
| 排程／立即生效 | 已備查版本的右卡提供台灣時間與立即生效操作             | 以伺服器回傳狀態為準；未來版本不提前套用；舊版本到實際區間終點才顯示停用                  |
| 停用           | 伺服器允許停用的版本提供理由及操作                     | 現行／未來已發布版本透過已備查替代版本接續；不憑空恢復另一個價格                          |
| 示範備查與跳過 | 同頁切換明示「示範」，維持左表右卡                     | 可示範備查不可用、跳過、排程、推進示範時間、重設及返回正式資料；零正式變更请求            |

所有生效時間清楚標示台灣時間（UTC+08:00），金額明示 TWD；夜間金額是
每趟固定加收。取整規則採使用者能理解的選項，不顯示資料庫或傳輸實作。

正式操作提交中不重複送出；失敗保留輸入及同一操作的重試 key，實際內容
變更才使用新 key。成功使用 API 回傳並讀回列表。衝突提示重新整理，不能
把失敗或示範狀態存成正式成功。讀取與提交交疊時，以最新操作的結果為準。

沿用現有 foundation:read／foundation:write 及平台角色：這只是既有服務
權限的消費，不新增授權機制。中英文文字與原 platform theme 保持一致。

驗證使用正式元件、SDK 與後端；HTTP、外部服務和儲存 transport 可模擬，
計價引擎不另造。VM 不啟動產品、預覽、瀏覽器或資料庫服務；真正 DB
交易由既有 hosted CI 執行。此功能不代表實際備查、供應商或全系統驗收完成。
