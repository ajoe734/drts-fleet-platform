關於我們

讓多平台供給與商務派車履約更穩定、更透明

智慧運輸科技股份有限公司是多平台計程車營運與商務派車合作平台。我們整合第三方叫車平台、企業派車、機場接送、保險代步、旅行社接送與車行供給，協助合作方提升派車履約效率與對帳透明度。

我們做的事

把分散的供給與需求，連成穩定的營運

司機端用一個工作台整合多平台任務；企業與合作方端用一套後台管理用車、審批與對帳；車行端用一套工具管理司機與分潤。我們專注於供給整合與履約，不接管合作平台的乘客關係與派單規則。
