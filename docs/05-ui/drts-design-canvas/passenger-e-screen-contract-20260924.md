# P5 乘客端 E-04 / E-18 / E-19 狀態與設計契約

此文件記錄 `UI17-PASSENGER-CANVAS-20260924` 任務引入的 P5 乘客端邊界狀態與設計規範。
依據新北市交通局 115.9.11 初審意見，實作下列補件：

## E-04 電子乘車證明（修正版 §91-6）
- **呈現欄位**：新增車隊／派遣業者（智行車隊）、駕駛遮碼及執登證號。
- **車資明細**：預設展開或可收合，包含起程、續程、延滯計時、夜間加成等法定項目。
- **支付與客服**：標示支付方式（如信用卡遮碼），並明列客服專線 `02-2944-0985`。
- **設計實作**：`P5_S10` 元件，透過 `detail={true}` 參數控制車資明細呈現。

## E-18 行程結束評分與低分導流
- **評分主畫面**（E-18）：預設展示 4 星與「做得好」標籤（如車內整潔、駕駛親切等）。
- **低分導流**（E-18b）：當評分 ≤2 星時：
  - 標籤自動切換為「待改善」（如駕駛態度、繞路等）。
  - 提供具體的補充意見文字區塊（限 200 字）。
  - 呈現「客服聯繫開關」，提示「開啟後送出將自動建立客訴案件」。
- **設計實作**：`P5_E18` 元件，透過 `stars` 參數（≤2 視為低分）控制條件渲染。
- **網域約定**：預設使用 repo 既有之 `ride.zhixing.tw`。

## E-19 費用與優惠說明及下單確認
- **費用與優惠說明**（E-19a）：
  - 列出 8 項定稿費用政策（車資、預約費、取消費、等待費、遺失物補償、清潔費、國道通行費、優惠活動）。
  - 政策文字為定稿，不得改寫；如「優惠活動」目前無，須明確標示。
  - 預設網址：`ride.zhixing.tw/fares`。
- **下單前確認 bottom sheet**（E-19b）：
  - 總結預估車資與支付方式。
  - 必須勾選「我已確認費用與優惠說明」方可送出。
  - **狀態約束**：未勾選時，確認按鈕必須具備實際的 `disabled` 屬性，且游標顯示 `not-allowed`，並提示需先勾選。
- **設計實作**：`P5_E19a` 與 `P5_E19b` 元件。

- 本次僅選擇性整併 E-04、E-18、E-19 增量，其餘 P5 頁面與外部依賴（如 `P5Phone`、`P5Header` 等共用殼層）維持不變。
- 此為靜態展示用之設計原稿與呈現，未實作對外後端呼叫或替換既有第一方 App。
