## 1. Scope & Defect Remediation Summary

### 1.1 `C042-F1` — Revenue Analytics Filter Population & Period Label Consistency
- **Root Cause**:
  1. `buildRevenueInsights` in `apps/ops-console-web/lib/ops-analytics.ts` filtered completed `driverTasks` joined with `orders` by `period`, `serviceBucket`, and `vehicleId` using `task.completedAt` and actual-fare-first (`toMinorAmount(task.fare) || toMinorAmount(order?.quotedFare)`), whereas `apps/ops-console-web/app/revenue/page.tsx` independently computed `periodOrders` from `orders.filter(o => o.status === "completed")` filtered only by `order.updatedAt` (ignoring `serviceBucket` and `vehicleId`) and summed `order.quotedFare` for `ownedTrips`, `totalTrips`, and `channelBuckets`.
  2. `normalizeRevenueTask` used `||`, causing a legitimate numeric `0` actual fare (`task.fare = { amountMinor: 0, currency: "TWD" }`) to fall back to `order.quotedFare`.
  3. `queuedRevenueMinor` called `matchesPeriod(order.createdAt, filters.period)` without forwarding `reference`.
  4. The first headline KPI label on `/revenue` was hardcoded to `t("revenue.kpi.billed", locale)` (`Billed (MTD)` / `當期 billed (MTD)`) regardless of whether `today`, `yesterday`, `7d`, or `30d` was selected.
- **Fix**:
  - Updated `buildRevenueInsights` (`apps/ops-console-web/lib/ops-analytics.ts`) to deduplicate canonical `orders`, `tasks`, and `statements`, preserve numeric `0` when `task.fare` is present (`task.fare !== null && task.fare !== undefined`), forward `reference` to `matchesPeriod`, and compute `ownedTrips`, `partnerTrips`, and `channels` from the exact same filtered `relevantTasks` population as `totalRevenueMinor`, `completedTrips`, `serviceBuckets`, and `vehicles`.
  - Updated `apps/ops-console-web/app/revenue/page.tsx` so `ownedTrips`, `totalTrips`, and `channelBuckets` derive directly from `insights`, replaced `(MTD)` in the headline KPI label via `formatRevenueBilledLabel`, reflected deep-linked/foreign `vehicleId` values in `renderFilterChips()`, and aligned `ordersAndTasksOk` across `buildHealthEnvelope`, `buildRevenuePageAvailableActions`, and `renderChannelMix()`.
  - Preserved independent reference views (`Settlement matrix`, `Mismatch review`, `Forwarded sync_failed %`, `Open recon issues`, `statementNetMinor`), read-only Ops boundaries, reconciliation deep links, and the Phase 1 disabled export descriptor (`disabledReasonCode: "phase1_no_export"`).

### 1.2 `C042-K1` & `C042-K2` — Attendance Canonical Date/Driver/Anomaly Filter Flow, Same-ID Drilldown, & Authorized Filtered Export
- **Root Cause**:
  1. `apps/ops-console-web/app/attendance/page.tsx` only read `searchParams.view` (`today` | `week` | `exceptions`), offered no date/driver/anomaly filter controls, and rendered driver labels as plain text without `/drivers/[driverId]` or `/vehicles/[vehicleId]` drilldown links.
  2. The header `<Btn variant="primary" icon="ext">{t("attendance.export", locale)}</Btn>` had no `href` or `onClick` handler and no `/attendance/export` route existed.
- **Fix**:
  - Added canonical attendance filter resolution, UTC boundary range evaluation, shift-to-attendance joining, anomaly classification (`all` | `anomalous` | `absent` | `partial` | `abandoned` | `present`), empty-state classification (`not_provisioned`, `no_data`, `filtered_empty`, `fetch_failed`, `permission_denied`), and RFC 4180 / formula-safe CSV serialization in `apps/ops-console-web/lib/ops-analytics.ts`.
  - Created `apps/ops-console-web/components/ops-attendance-filter-export.tsx` (`OpsAttendanceFilterBar`, `OpsAttendanceExportButton`, `OpsAttendanceFilterExport`) and wired it into `apps/ops-console-web/app/attendance/page.tsx`.
  - Created `apps/ops-console-web/app/attendance/export/route.ts` (`GET /attendance/export`) using `getServerOpsClient()` (preserving verified IAP/control-plane request auth) and the shared canonical filter/projection pipeline, returning `text/csv; charset=utf-8` on success and truthful `401`/`403`/`502` JSON errors on auth/upstream failure without leaking hidden driver PII.
  - Added same-ID `/drivers/[driverId]` drilldown links in both the Gantt chart and Shift & Attendance Records table, plus `/vehicles/[vehicleId]` links on vehicle cells.
