## Production paths and storage boundaries

Null means no bound; no TTL is invented. Schedule activates at `now >= start`; expiry downlists at `now >= end`. Admin history retains resolved records and correlated outcomes. Manual resolve and maintenance enabled/reason/window configuration remain; this change adds no platform traffic-blocking policy.
- Notice state, audience route records, notification records and per-principal read receipts use **process memory**. Notice ACK/readback explicitly returns `storageMode: process_memory`. Reconciliation occurs on production reads/commands, without a global scheduler. This is not durable cross-restart, multi-instance or provider/device delivery.

Failed insertion records `failed` and returns failure; missing correlated records become `unknown`. Root routing records remain `routed` until specific receipts exist.
