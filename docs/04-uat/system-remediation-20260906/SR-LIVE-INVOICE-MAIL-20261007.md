### Implementation Details

- **Test Harness**: Required fix for env mapping in bootstrap and teardown to use `DRTS_LIVE_INVOICE_MAIL_*` variables via an adapter.
- **Strict Evidence Validation**: Required fix to `gate-evidence.py` to prevent false positives and verify actual identity, binding, download bytes, and idempotency.

- **Contract Adherence**: Restoring out-of-scope product changes (e.g., NestJS controller, `ci-integ.yml`). Resolving absolute origin and exact allowed-origin policy in tests.
- **CI**: Fixing unauthorized CI edits and registering same-SHA source checks in the allowed new workflow (`.github/workflows/live-invoice-mail-acceptance.yml`).
