# 一般調度詳情同步司機行程

一般調度看板已有 DispatchAutoRefresh，詳情頁卻只有 T2／5 秒的更新標示，沒有掛上該元件。即使司機已改變同一筆後端任務，調度詳情仍會停留在上一次讀取的狀態。

詳情沿用既有五秒更新元件及原有 API，終態後停止更新。原始訂單與目前任務保持可見，任務狀態使用本次伺服器讀回值。

原 A 旅程在一般調度完成指派及改派後，維持同一詳情頁，逐一等到司機接單、前往、抵達、開始、完程的新狀態。這段過程不重新導航、不手動重整、不替代內部回應，另外保留接單與完程兩張原圖；原階段、時間及關聯斷言不變。其他情境不改。

本地只執行型別、lint 與既有單元檢查。真正的三端瀏覽器及 PG 旅程由託管 CI／共享環境驗證，完成前不列為同版本旅程通過。人工調度同步不代表建單自動派車串接已完成。
